# 刑小狮桌宠 · 网页扩展

这是 `dsh-lion-pet` 的 Chrome / Edge 通用网页版。它和 DSH 插件共用同一套狮子素材，但独立安装、独立开关。

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录（`extension/`）。
4. 打开任意 http(s) 网页，右下角会出现刑小狮。

## 使用

| 操作 | 效果 |
| --- | --- |
| 单击刑小狮 | 摸摸头、撒星星、随机台词 |
| 按住拖动 | 搬到页面任意位置，位置会记住 |
| 右键 | 摸摸头、换姿势、缩放、回到右下角、隐藏 |
| 点扩展图标 | 在网页上显示 / 关闭 |
| 弹窗里的「恢复默认位置」 | 清掉保存的坐标，刷新页面后回到右下角 |

扩展只申请 `storage` 权限和 http(s) 网页注入权限；不读取页面内容，不发送网络请求。

## 与 DSH 插件的关系

- DSH 设置里的「显示模式」只控制 DSH 页面内的宠物和桌面悬浮窗。
- 这个扩展只控制其他网页上的宠物。
- 两边都关闭时，宠物完全不会出现。
